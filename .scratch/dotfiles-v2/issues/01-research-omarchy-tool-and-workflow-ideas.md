# Research Omarchy tool and workflow ideas

Type: research
Status: resolved

## Question

Which Omarchy tools and workflows are relevant to a Fedora KDE Plasma developer desktop, and which are unsuitable because they depend on Omarchy, Hyprland, Arch Linux, or another specific environment? Provide a compact, source-linked inventory that supports later profile selection.

## Answer

[Omarchy tool and workflow ideas](../research/omarchy-tool-and-workflow-ideas.md) identifies `mise`, Tmux, optional Git and Docker TUIs, terminal choice, and LocalSend as candidates. It excludes the Arch, Hyprland, Quickshell, and Omarchy-owned installation layers.
