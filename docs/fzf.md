# FZF

## Keybindings

_(Default)_ means fzf or the fzf.fish plugin provides the binding. _(Custom)_ means this setup adds or changes the binding.

### Fuzzy Search

- `Ctrl+Alt+f` - Search for a file in the current directory. _(Default)_
- `Ctrl+Alt+l` - Search commits in the Git log. _(Default)_
- `Ctrl+Alt+s` - Search files in Git status. _(Default)_
- `Ctrl+Alt+p` - Search for a process. _(Default)_
- `Ctrl+r` - Search command history. _(Default)_
- `Ctrl+v` - Search environment variables. _(Default)_

### Navigation

- `Ctrl+p` - Move to the previous entry. _(Default)_
- `Ctrl+n` - Move to the next entry. _(Default)_
- `Tab` - Select multiple entries. _(Default)_
- `Enter` - Confirm the selection. _(Default)_
- `Esc` - Cancel and exit. _(Default)_
