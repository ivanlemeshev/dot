This repository uses the single-context layout. See `docs/agents/domain.md`.

## Language style

Use ASD-STE100 Simplified Technical English for all communication. Use short, direct sentences. Use one meaning per word where possible. Avoid idioms, vague language, and unnecessary complexity.

### Code comments

Add a comment only when it gives necessary information that the code cannot clearly show. Keep each comment short, clear, and current. Do not restate the code.
